# 게임 규칙과 기준 계약

원본 §3–7, §12, §14, §16. 기준 코드는 src/game에 있으며 아직 전체 게임에 통합되지 않았다.

## 고정 규칙과 조정값

| 구분 | 값 |
|---|---|
| 성공 기준 | rawScore >= 700, 모든 캐릭터 동일 |
| 입력 | 해제 후 새로운 입력 두 번; 두 번째에 즉시 발사 |
| 파워 | 0–100 자동 왕복, 홀드 충전 아님 |
| 수평 방향 | -60°–+60°; 상하 조작 없음 |
| 점수 지수 | 파워 1.1, 정확도 1.6 |
| 초기 전체 왕복 주기 | 파워 2200ms, 각도 3000ms |
| 주기 하한 | 파워 1200ms, 각도 1700ms |
| 목표 방향 | 첫 런 라운드는 중앙, 이후 초기 ±12° 범위 |
| 연출 구분 초기값 | 고파워 0.85, 근접 실패 650 |

“첫 라운드”는 매 런의 첫 라운드로 해석한다. 조정은 라운드 사이에만 한다.
속도 증가 함수와 패드 반경·거리는 M1 플레이 테스트에서 결정한다.
fixture의 반경·거리는 검사용 값이며 제품 난이도 확정값이 아니다.
고정 규칙은 RULES, 조정 목표는 TUNING으로 관리한다.

## 점수

~~~text
P = clamp(powerPercent / 100, 0, 1)
u = 패드 로컬 x 중심 오차 / 가로 반경
v = 패드 로컬 y 중심 오차 / 세로 반경
d² = u² + v²
hit = 정방향 패드 평면 접점 존재 AND d² < 1
accuracy = hit ? clamp(1 - d², 0, 1) : 0
rawScore = round(1000 * P^1.1 * accuracy^1.6)
maxRawScore = round(1000 * P^1.1)
canStillSucceed = maxRawScore >= 700
isSuccess = rawScore >= 700
~~~

round는 음수 아닌 수의 0.5 이상 올림. 경계 d=1은 비명중이다.
파워 0의 중앙 접점은 hit=true, accuracy=1, rawScore=0이다. 피해·패드 변형은 발생하지 않는다.
NaN·Infinity·비정상 좌표는 개발 경계에서 오류 처리하고 사용자 입력 경로에서 차단한다.

정중앙 최대 예: 60→570, 70→675, 75→729, 100→1000.
성공 가능 경계는 round를 포함하므로 100 × ((700 − 0.5) / 1000)^(1 / 1.1)에서 유도한다.
UI는 72.3이라는 표시 근삿값으로 판정하지 않는다. 경계 부근 안내도 maxScore 함수를 사용한다.
부족 점수 = 700 − rawScore. 정확도 표시 = accuracy × 100.
문구 예시·실제 HUD 모두 같은 계산 결과를 사용한다.

콤보는 이번 성공을 포함한 연속 성공 수 n에 대해 min(1 + 0.1(n−1), 2).
획득 점수 = round(rawScore × 콤보), 성공 라운드만 지급. 실패는 0점 추가다.
699 × 2를 성공으로 바꾸거나 실패 수집에 점수·콤보를 주지 않는다.

## 실패 분류 순서

성공이면 null을 반환하고 결말 선택 자체를 건너뛴다.

| 순서 | 유형 | 조건 |
|---|---|---|
| 1 | HIGH_POWER_MISS | !hit AND P >= 0.85 |
| 2 | MISS | !hit AND P < 0.85 |
| 3 | NEAR_SUCCESS | hit AND 650 <= rawScore < 700 |
| 4 | UNDERPOWER_HIT | hit AND maxRawScore < 700 |
| 5 | OFF_CENTER_HIT | 나머지 실패 명중 |

예: 파워 70 중앙 675점은 파워도 부족하지만 우선순위상 NEAR_SUCCESS다.
fallback은 같은 실제 유형의 공통 모듈이며, 비호환 장면을 사용하기 위해 유형을 바꾸지 않는다.

## 좌표·시간·입력

검증 좌표계: 월드 Y 위, 0°는 -Z, +각도는 +X. 패드는 로컬 XY 평면의 타원이며 +Z 면이 발사 원점을 향한다.
ray를 패드의 역변환으로 옮겨 로컬 z=0 접점을 구한 뒤 u/v를 계산한다.
비가역 변환은 거절한다. 뒤쪽·평행·발사 원점 뒤 평면은 접촉이 아니다.
화면 이동으로 조준을 속이지 않고 실제 패드 월드 위치를 이동한다.
렌더링 장갑의 둥근 끝점은 같은 ray와 접점을 사용해야 한다. 이 시각 통합은 M1에서 구현한다.

공통 시계는 performance.now와 같은 단조 시각을 받으며, 중지 시간은 제외한다.
왕복값은 게임 시각·주기·초기 위상의 함수다. RAF와 입력 핸들러에서 같은 함수를 호출한다.
POWER와 AIM 진입 시각 및 각자의 초기 위상을 저장한다.
pointerdown을 주 액션으로 사용하고 click을 다시 발사에 연결하지 않는다.
pointerup/cancel, keyup 뒤 새 입력만 다음 단계를 확정한다. 키 repeat·멀티터치를 무시한다.
설정·언어·스킵·재도전 이벤트가 발사로 전파되지 않게 한다.
M1-01에서 shot-input과 DOM action-input 어댑터를 구현했다. 별도 브라우저 fixture로 입력 연결을 검증하며, 제품 화면·좌표·연출 통합은 후속 단계다.
