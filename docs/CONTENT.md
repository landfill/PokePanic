# 캐릭터·연출·아트 제작 명세

원본 §2, §6–8, §10–11을 기준으로 한다.
content-plan.json은 **제작 계획**이며 로더에 넣을 runtime manifest가 아니다.
나이·영문 이름·리그 치수·애니메이션 키프레임은 구현 중 확정한다. JSON의 성인 나이는 임시 제안이다.

모든 인물의 성인 체형을 확인한다. 성별을 reactionType의 자동 분기로 사용하지 않는다.
조준 단계에 얼굴·머리·가슴·발·이름·직업·그림자·반사·가장자리 소품이 보이지 않도록 한다.
완전한 모델을 처음부터 준비하고 같은 모델을 카메라 후퇴와 회전으로 공개한다.

## 실패 계열과 호환 계약

| 계열 | 허용 유형 | 필수 동작 |
|---|---|---|
| DELAYED_NOTICE | UNDERPOWER_HIT, OFF_CENTER_HIT | 정적 → 시선 → 정체 공개 → 인물 고유 반응 |
| FALSE_RELIEF | NEAR_SUCCESS | 무릎 꺾임 → 이른 세리머니 → 다시 일어남 → 고유 반응 |
| SELF_OWN | HIGH_POWER_MISS | 옆을 지남 → 반동 회전 → 매트 → 멀쩡한 상대 |
| AWKWARD_MISS | MISS | 지나감 → 숨김 → 삑 소리 → 민망한 퇴장 |
| FAKE_FORGIVENESS | UNDERPOWER_HIT, OFF_CENTER_HIT, MISS | 용서 미소 → 안도 → 카메라 후퇴 → 대기 중인 연행/퇴장 |

FAKE_FORGIVENESS는 민원 여왕·비밀 심판·미소의 경호원만 초기 허용한다.
근접 실패는 실제 점수를 유지하며 정확히 699점일 때만 제목에 699를 쓴다.
MISS 계열에서 패드 변형·접촉음·아픈 동작을 만들지 않는다.
같은 유형 내 여러 후보는 아직 감상하지 않은 결말을 우선한다. 후보 정렬과 난수 시드를 고정한다.
후보가 비면 같은 failureType의 공통 모듈을 사용하고 개발 검증에서는 데이터 오류를 기록한다.
현재 계획은 8개 고유 대표 장면과 4개 공유 장면의 12개 ID다.
이 숫자는 완성된 수집 개수가 아니다. 실제 동작·구성·마지막 반전 검수 후만 별도 ID로 인정한다.
이름·대사·의상 색 차이는 ID가 아니라 하위 변형으로 둔다.

## 타임라인과 수집 이벤트

발사 → 접촉/비명중 → 점수 표시 → 전신 공개 → 본편 → 결과.
접촉 정지감 60–90ms, 공개 후 성공 1–2초, 실패 본편 3–5초를 초기 목표로 둔다.
성공 라운드 8–12초는 입력을 기다리는 강제 시간 제한이 아니다.
각 타임라인은 enter/update/finish/cleanup, 핵심 장면 마커, roundId, skip 정책을 가진다.
구체적인 초 단위 키프레임은 M1 이후 실측하여 채운다.
해금은 플레이로 본편에 도달할 때, 감상은 핵심 장면 또는 정상 완료 시 기록한다.
이미 본 동일 ID는 시작부터 스킵 가능. 새 결말 최소화는 해금만 유지한다.
새 결말 배지는 결과에서만 표시한다. 게임오버가 본편을 먼저 덮으면 실패다.

## 제작할 에셋과 검수

| 제작물 | 최소 검수 기준 |
|---|---|
| 폼 장갑 | 결합한 두 손·엄지·접힌 손가락·둥근 끝·손목·소매, 충돌 기준 끝점 |
| 바지·패드 | 허리밴드·봉제선·포켓·주름·재질 구분·패드 테두리·힘에 따른 변형 |
| 전신 리그 | 성인 비율, 목·어깨·골반 연결, 손목 소켓, 자연스러운 회전 |
| 얼굴 | 평상·놀람·분노·무표정·당황·능청, 눈썹과 시선 별도 제어 |
| 경찰·경비·수갑 | 손목 소켓과 연결된 체인, 관통·공중 부유 없음 |
| 촬영장 | 바닥·벽·간판·안전 매트, 접지 그림자, 배경이 조준을 방해하지 않음 |
| SVG | 게이지·120° 부채꼴·충격선·말풍선·점수·별; 번역 가능한 실제 텍스트 |
| 사운드 | 게이지 틱·확정·스프링·고무 접촉·성공·정적·낮은 사이렌, 과격한 비명 없음 |

디자이너 토이 입체감·만화 그래픽·명료한 아케이드 조작이 방향이다.
남청색·크림·코랄·청록이 출발점이며 정식 토큰·모델은 아직 제작하지 않았다.
GLB 또는 bevel·곡선·재질·표정 파츠를 가진 절차 메시를 사용한다.
막대·구체 마네킹이나 정적 이미지 교체는 최종품이 아니다.
장갑·바지·패드 근접 품질을 우선하고 그다음 얼굴·상체를 다듬는다.
에셋 확보 후 경로·저작자·원본 URL·라이선스·수정·생성 소스를 ASSET_LICENSES.md에 기록한다.
