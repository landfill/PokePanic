# 대표 두 인물 플레이 검수

2026-09-12. A 토이 스튜디오 방향. 사용자에게 비교판을 제시하고 A 선택을 기록했다.
현재 구현은 절차 메시 기반 대표 제작물이며 비교판의 고해상도 이미지와 같은 품질을 달성했다고 주장하지 않는다.

## 현재 구현과 자동 검증 범위

- 0–450ms 발사, 850–1900ms 같은 배우 공개, 실패 본편 1900–5900ms, 성공은 3900ms 종료.
- 철근: 실제 손·플레이어 옷깃 위치 연결, 들어 올림·먼지·매트의 납작한 장난감 자세.
- 민원: 휴대전화 동작·경찰 진입·두 손목 소켓의 소품 수갑·체인·동반 퇴장.
- 비명중은 상대에게 접촉/패드 변형을 만들지 않는다. 고파워는 자기 회전·매트 착지, 보통은 숨기기·삑 표시·퇴장.
- 근접 실패는 잠깐 내려앉음·이른 세리머니·회복 뒤 고유 반응. 699를 성공으로 바꾸지 않는다.
- 성공은 같은 배우의 균형 상실과 소품 반응이며 반격·체포로 번복하지 않는다.
- 점수·패드·옷깃/손목 연결·멱등 종료·반복 프레임 결정성을 코드와 단위 테스트로 검증한다.

## 발견과 조치

1. 회전값을 프레임마다 누적하던 연출을 초기 포즈에서 같은 시각의 값으로 재계산하도록 수정했다.
2. 옷깃 잡는 위치가 0.32m 어긋난 초기 코드에서 실제 월드 손 소켓과 일치하도록 변환을 수정했다.
3. 360px 화면에서 경찰·플레이어·수갑이 잘렸다. 본편 카메라를 후퇴하고 경찰과 플레이어를 함께 이동시켰다.
4. 성공 때 머리가 잘리고 몸 기울임이 약했다. 더 큰 균형 상실과 바닥 침투 보정, 본편 카메라를 적용했다.
5. 접점 평면이 패드 메시 중심에 있어 0.045m 안쪽까지 들어가던 문제를 앞면 평면으로 수정했다.

## 아직 분리해서 확인할 것

현재 테스트는 참가자 관찰이 아니다. 실제 재미·반전 이해·재도전 의도·반복 연출 피로는 미검증이다.
대표 동작의 프레임 캡처는 연속 영상과 실기기 성능을 대신하지 않는다.
피부·성인 비율·손과 표정·의상·소품 연결의 시각 품질, 의도한 코미디 강도는 계속 검수한다.
M3의 8인물 대량 확장 전 짧은 플레이에 대한 미결 제품·취향 선택을 사용자와 확인한다.
