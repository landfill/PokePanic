두 인물의 짧은 반전

A 토이 스튜디오 방향으로 만든 실제 3D 연출입니다. 아래 영상은 두 인물 모두 파워 60%, 정중앙 접촉 570점인 같은 실패에서 시작합니다.

철근 씨

늦은 눈치 → 옷깃 잡기 → 먼지 속 난투 → 매트 위 장난감 자세.

민원 여왕

휴대전화 → 대기 경찰 → 두 손목의 소품 수갑 → 함께 퇴장.

직접 플레이하기 · 검수 기록

확인할 경험은 실패 이유를 이해할 수 있는지, 반전이 원하는 코미디에 가까운지, 한 번 더 시도하고 싶은지입니다. 메시·얼굴·의상·소품의 세부 품질과 실기기 성능은 계속 보완 중입니다. 영상은 360×600 소프트웨어 Chromium 캡처이며 휴대전화에서 직접 측정한 결과는 아닙니다.
