# ADR 0001 — 개발 준비 기준

날짜: 2026-09-11. 상태: 이번 하니스의 기준으로 채택.

## 맥락

빈 저장소에 원본 메타 프롬프트 한 개가 있으며 사용자 요청은 필요한 문서와 하니스 구성이다.
원본에는 전체 게임 제작을 명령하는 표현이 있지만 이번 작업의 직접 요청과 구분한다.

## 결정

1. 서비스 영어 표기는 사용자 지정 Poke & Panic. 원본의 POKE & PANIC은 로고 대문자 스타일로 허용.
2. 원본은 그대로 보존. 새 문서는 기준을 추적·검증 가능한 형태로 정리한다.
3. M0 범위는 문서, Vite/TypeScript/Three.js 환경, 계산 기준, 테스트, CI다.
4. 백엔드·계정·DB·외부 API·프레임워크·물리 엔진을 추가하지 않는다.
5. 게임 시계와 계산을 먼저 고정하고 상태·입력·3D 연결은 M1에서 수행한다.
6. 첫 라운드 중앙 배치는 각 런의 첫 라운드로 해석한다. 백은 런과 독립한다.
7. 캐릭터 나이와 결말 ID는 제작 계획 초깃값이다. 완성 에셋·확정 수집 개수로 주장하지 않는다.
8. 규칙 700점은 고정, 650/0.85·주기·DPR 등은 초기 조정 목표로 분리한다.
9. 감상하지 않은 후보 우선은 seen 기준, 해금은 unlocked 기준으로 나눠 추적한다.
10. 신규 준비 화면은 환경 확인 전용이며 M1 제품 화면으로 교체한다.

## 결과와 후속

하니스 통과만으로 게임 제작이 끝난 것처럼 보이지 않도록 STATUS와 요구사항별 상태를 유지한다.
패드 반경·거리·난이도 증가 함수, PRNG 알고리즘, 영어 인물 이름, 최종 아트는 해당 구현 단계에서 결정한다.
원본과 충돌하는 변경은 새 ADR에 원인과 수용 기준 영향을 명시한다.
