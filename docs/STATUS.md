## M1 원인별 연출·M2 수집/재현 연결 — 2026-09-12

현재 브랜치는 codex/feat/m1-two-actor-loop로 이름을 맞췄다. 기준 커밋은 기존과 같고 미커밋 변경을 보존했다.

## 중간 커밋을 위한 구현 단계 점검 — 2026-09-12

사용자가 현재 단계를 확인하고 중간 커밋을 요청했다. 진행 중인 타입 연결을 마무리하고 기능 상태를 구분했다.

| 단계 | 현재 확인한 범위 | 남은 범위 |
|---|---|---|
| M1 | 두 입력·실제 좌표/점수·공개·대표 반응·첫 실패 종료·재도전 연결 | 전체 품질 수용 기준 최종 확인 |
| M2 | 셔플백·저장·호환 결말·스킵·해금/감상·도감 격리 재생·기록 재현 | 8인물 통합 회귀 확대, 상세 개발 패널 보완 |
| M3 | 8 전신 리그, 12 runtime 결말, 40 호환 조합과 초기 고유 동작 연결 | 신규 6인물의 고유 성공/실패 연출·시각 품질 검수 |
| M4 | 저장 오류·미래 스키마·WebGL 복구의 브라우저 검증 일부 확보 | 실기기 성능·접근성·플레이 관찰·원격 CI/배포 |

중간 커밋은 제품 완성/출시 완료를 의미하지 않는다. requirements는 implemented와 미완료 내용을 함께 기록했고 verified로 올리지 않았다.
8인물 확장 후 npm run check 통과: 20 파일/201 단위 테스트, 타입·빌드·하니스.
실제 JS 번들은 약603kB/gzip158kB이며 기존 500kB chunk 경고가 남아 있다.
최신 8인물 연결 빌드의 제품 Chromium E2E도 16개 통과했다 (입력/중지/도감 10개 + 저장/WebGL 복구 6개).
중간 커밋 직전 별도 입력/연출 검증도 24개 통과했다. 동일 연출의 중복 모바일 캡처 10개는 의도적으로 제외했다.
이번 사용자 요청에 따라 이 검증된 작업 트리를 로컬 중간 커밋으로 저장한다. 원격 push는 요청하지 않아 수행하지 않는다.
