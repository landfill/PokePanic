# 제품 요구사항

## 한 문장

똥침각 / Poke & Panic은 파워·수평 각도를 두 번의 타이밍 입력으로 확정하고,
성공 시 기록을, 실패 시 실제 원인에 맞는 정체 공개와 코미디 결말을 얻는 모바일 웹 아케이드다.

주요 사용 맥락은 짧은 여유 시간에 브라우저에서 즉시 시작하고 한 번 더 시도하는 것이다.
성공률·이탈률·재도전율의 목표 수치는 아직 정하지 않았다. 관찰 없이 재미 점수를 만들지 않는다.

## 필수 경험과 용어

라운드 = 상대 한 명, 런/한 판 = 시작부터 첫 실패까지, 프로필 = 여러 런에서 유지되는 기록.

등장 → 파워 → 각도·자동 발사 → 접촉/비명중 → 판정 표시 → 같은 인물의 전신 공개
→ 성공이면 다음 상대, 실패이면 원인별 연출 → 게임오버 → 한 번 입력으로 새 런.
낮은 파워로 성공 가능성이 없어져도 각도 선택을 유지한다.

## 1차 제품 범위

- 8개 성인 캐릭터, 각 인물의 대표 실패·짧은 성공 반응.
- 5개 실패 유형과 5개 공통 코미디 계열. 미발견 우선은 호환 후보 내부에서만 적용.
- 공통 크기·높이의 실제 타원 패드, 공정한 점수식, 라운드 사이 좌우 배치 변화.
- KO/EN 즉시 전환, 음소거, 연출 최소화, 움직임 감소·흔들림 설정.
- 로컬 최고 기록·발견·감상·등장 백, 해금 결말의 독립 재생.
- 저장 실패·에셋 실패·오디오 거절·WebGL 2 미지원·context loss 복구.
- 모바일 세로 360px부터, 가로 배치, 데스크톱 키보드, Vercel 정적 빌드.

라이프, 부활, 재발사, 유료 대기·광고 강제, 도주로 런 연장, 숨겨진 파워대,
정체 추리, 서버·회원가입·DB·결제·글로벌 랭킹·필수 외부 API는 제외한다.
공유는 핵심 플레이 이후의 선택적 텍스트 공유/복사다.

## 화면과 문구

| 화면 | 핵심 정보와 행동 | 수용 기준 |
|---|---|---|
| 시작 | 이름, “각은 봤고, 앞은 못 봤다.”, 시작 안내 | 설명 랜딩페이지·긴 스크롤 없음 |
| 조준 | 라운드·누적·최고, KO/EN·음소거·설정, 패드·장갑, 기준 700, 게이지 | 정체 단서·결말 스포일러 없음 |
| POWER | 왕복 게이지, 정중앙 성공 가능 경계, “파워 결정” | 색 외 눈금·패턴 |
| AIM | “각도 결정 · 발사”, 정중앙 최대 점수·파워 부족 안내 | 가이드·장갑·판정이 같은 방향값 |
| 결과 | 얼굴, 판정, 실제 원인, 누적·최고, 새 결말, 재도전 | 핵심 반전 뒤 표시, 재도전 우선 |
| 도감 | 발견 인물과 해금 결말, 감상 여부 | 잠긴 제목·정체 숨김, 재생으로 런 변경 없음 |
| 오류/중지 | 상황과 재시도/재개 | 무한 로딩·미구현 2D 모드 없음 |

액션 버튼 높이 약 64px, 보조 터치 영역 최소 44×44 CSS px를 목표로 한다.
동적 뷰포트와 safe-area, 가로 재배치, 영어 긴 문구를 확인한다.
입력 영역만 touch-action을 조정하고 전체 페이지 확대를 차단하지 않는다.

## 표현·접근성

가상 쇼에 자발적으로 참가한 20세 이상 성인 배우, 둥근 폼 장갑과 바지 외부 보호패드를 사용한다.
경찰과 체포도 쇼 소품 연출이다. 웃음의 대상은 앞을 보지 않고 도전한 플레이어의 무모함이다.
노출·관통·혈액·배설물·성적 연출·현실적 부상은 표현하지 않는다.
시작 화면 하단 안내: “성인 배우들의 만화적 슬랩스틱입니다. 실제로 따라 하지 마세요.”

Space/Enter, 포커스 표시, 접근성 이름, 단계·결과만 읽는 live region을 제공한다.
음소거로도 원인·판정을 알 수 있어야 한다. 오디오는 첫 입력 후 초기화하며 거절을 처리한다.
prefers-reduced-motion은 기본값에 반영하고 필수 게이지 운동은 유지한다.
언어 우선순위는 저장 선택 → 브라우저 한국어 → 영어이며, 전환해도 런·시계·상대가 유지된다.
