# 현재 디자인 결정과 인계

기준일: 2026-09-11. 상태: A 토이 스튜디오 채택, 대표 캐릭터·짧은 플레이 제작 진행.

## 합의된 방식

[디자인 진행 절차](DESIGN_WORKFLOW.md)에 따라 레퍼런스 조사 → 2~3개 방향 시안과 추천 →
대표 1~2명 시트와 화면 → 짧은 플레이 검증 → 콘텐츠 확장으로 진행한다.
작업자가 디자인 품질을 평가하고 추천하며 사용자는 경험·취향·제품 방향을 판단한다.
이번 요청은 이 방식을 지침에 남기는 것이며 조사·시안·게임 구현 착수 요청은 아니다.

## 아직 결정하지 않은 사항

- 최종 레퍼런스와 적용 근거: 미선정. 이전 대화의 소개 페이지 조회는 조사 완료로 취급하지 않는다.
- 최종 아트 스타일·팔레트·타이포 토큰: 미선정. CONTENT의 기존 방향은 출발점.
- 비교 시안·대표 캐릭터 시트·짧은 플레이 결과: 아직 없음.
- 사용자 선택 또는 디자인 결정 위임: 아직 없음.

다음 허용 작업: 현재 요청 범위의 문서·스킬 정비. 후속 디자인 작업 요청을 받으면 해당 범위부터 진행한다.
결정이 생기면 아래 필드를 채워 실제 기록으로 갱신한다. 기존 결정을 바꿀 때 이유와 대체 기록을 연결한다.

| 결정 항목 | 상태 | 근거·시안 경로 | 사용자 선택·위임 및 날짜 | 남은 질문·다음 작업 |
|---|---|---|---|---|
| 전체 시각 방향 | A 채택 | design/m1-directions/index.html | 사용자 A 선택, 2026-09-11 | 대표 두 인물·실제 장면 제작 |

## 2026-09-11 시각 방향 선택

사용자가 비교판을 확인하고 “A 토이 스튜디오 (추천)”를 선택했다.
[비교 시안](design/m1-directions/index.html), [추천 근거](design/m1-directions/REVIEW.md),
[생성 기록](design/m1-directions/PROMPT.md). 남청·크림·코랄·청록과 부드러운 무광 입체감을 채택한다.
선택한 것은 전체 분위기다. 생성 이미지의 장갑 형태·패드 일관성은 제작 계약에 맞춰 실제 메시에서 수정한다.
대표 두 인물 시트·전신 리그·실제 조준/공개·짧은 플레이는 아직 검증 전이다.
승인된 방향 안의 세부 가독성·리그·카메라·버그 수정은 작업자가 진행한다.
초기 “문서만 정비 허용” 기록은 당시 요청의 과거 이력이며 현재는 사용자 구현 착수·계속 지시가 적용된다.

## 2026-09-12 대표 플레이 후 확장 선택

[대표 영상·플레이 자료](design/m1-playtest/index.html)를 제시한 뒤 사용자가
“현재 템포·반전을 유지해 확장 (추천)”을 선택했다.
현재 공개 후 약 4초의 실패 본편과 난투·소품 수갑 반전을 유지하여 8인물로 확장한다.
이는 코미디 방향에 대한 사용자 선택이다. 시각 품질·성능·실기기 검수 완료나 정량적 재미 검증으로 해석하지 않는다.
